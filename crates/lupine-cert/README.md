# lupine-cert

X.509v3 certificate generation and validation for the Lupine PQC suite.

Supports self-signed and CA-signed certificates using ML-DSA (FIPS 204) and
hybrid Ed25519+ML-DSA signature algorithms.

## Status

Part of the [Lupine](https://github.com/im40percentgit/lupine) post-quantum
cryptography workspace.
